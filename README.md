# 寄出之前｜中研院RCCI實驗室營業秘密情境小遊戲（v2.0）

一款以 GBA 時代俯視角像素 RPG 為靈感的純靜態網頁小遊戲。玩家扮演「中研院RCCI實驗室」的值班研究助理**小安**，與同事**阿文**及負責人**阿明組長**互動，透過兩個獨立章節練習實驗室營業秘密保護的日常決策與補救應變。

- **純靜態網頁（HTML / CSS / JavaScript）**：零外部相依、無後端、無須建置流程，所有資源皆採相對路徑。
- **本機試玩方式**：在 Windows 直接雙擊開啟 `index.html` 即可於瀏覽器遊玩，不須架設伺服器；亦支援直接部署至 GitHub Pages（含專案子路徑）。
- **操作方式**：
  - 電腦：方向鍵 / `WASD` 移動，`Space` / `Enter` 互動確認，`Esc` 關閉視窗。
  - 手機 / iPad：畫面自動顯示虛擬方向鍵與 `A`（互動）／ `B`（返回或筆記）鍵；電腦版亦可點右上角「🎮 搖桿」切換測試。
  - 上方工具列隨時提供「📋 筆記」「🏆 圖鑑」「🔄 重來」「🏠 選單」「🔊 音效」，重來僅重置當前章節進度，保留已解鎖的結局紀錄。
- **虛構演練情境**：角色、合作方、海報與研究資料皆為虛構演練素材。

## 章節與玩法說明

首頁提供兩個章節入口，**兩章皆可直接進入，無須先破完第一章**。

### 第一章「寄出之前」（下午 15:40）

下班前處理兩項可任意排序的突發任務，並保有 5 種交班結局圖鑑：

1. **先查證（確認 NDA 簽署＋版本）再提供路線**：
   到辦公區電腦讀信 → 先透過電腦「📑 查詢實驗室 NDA 合約清單」或找辦公區**阿明組長**完成 **NDA 簽署查核關卡**（確認星海科技已簽署有效 `NDA-CS-2026`、在效期內且涵蓋範圍不含原始數據與協力廠商；必要時可先回覆「正在確認中」）→ 找實驗區同事**阿文**解鎖會議用兩張圖 → 回電腦僅分享核准兩張圖，設定指定收件人唯讀與 7 天效期。
2. **誤寄後補救路線**：
   在電腦將整個 `ClearSky_TestData` 資料夾設成「持連結者皆可存取」寄出 → 收到合作方詢問能否轉傳協力廠商的急信 → 立刻回電腦**停用公開連結** → 找負責人**阿明組長**完成四要素通報（發現時間、涉及資料、使用系統、目前情況）。
3. **訪客拍照雙路線**：
   - 在**訪客入口指定角度**拍形象牆（核准範圍）。
   - 或**陪同進入實驗區**看相機預覽 → 發現白板／螢幕／樣品標籤入鏡時按「暫停拍攝」→ 整理現場後重拍。

### 第二章「投稿前一晚」（晚上 18:00）

阿文在辦公區門口請玩家協助確認今晚要交的研討會海報草稿（內含三張示意圖：圖一「設備配置示意」可公開、圖二「合作方量測圖」曾用於合作會議、圖三「測試條件與結果摘要」涉及尚待確認的專利申請安排）。

可自由走動調查**辦公區電腦**、**實驗區的阿文**（說明圖二來源並解鎖替代圖）與**辦公區的阿明組長**（詢問「現在哪張圖能用？」與「整理好之後怎麼確認版本？」），並在電腦比較「原始草稿」與「目前編輯版本」、送審核准與自選檔案提交。

#### 第二章三條測試路線

1. **核准後提交**：
   - 先到辦公區電腦看草稿（此時圖二顯示「來源待確認」且替代圖鎖定）→ 到實驗區找**阿文**確認圖二原用於合作會議並取得替代圖 → 找辦公區**阿明組長**確認公開規則與專利安排 → 回電腦替換圖二、移除圖三、送交阿明組長確認 → 找**阿明組長**核准該版本 → 回電腦核對檔名後提交核准版 → 回值班桌交班。
   - *額外驗證版本綁定*：取得核准版後再次編輯海報，確認會產生「待重新確認」的新版本，且原核准版紀錄保持不變。
2. **暫緩提交**：
   - 在未取得完整確認或發現合作資料公開用途／專利申請安排尚待確認時，於電腦「版本紀錄與提交投稿」分頁選擇**「暫緩上傳」** → 回值班桌交班，確認列出待確認的圖片、原因與下一步。
3. **誤傳舊版後補救（含未完成補救即交班）**：
   - 取得核准版後（或未核准前），在提交畫面故意選取未確認的舊版（如 `Poster_v1_原始草稿.pdf`）上傳 → 觸發誤傳警報。
   - **補救完成**：回電腦點「聯絡主辦方提出撤換請求」（顯示「已提出撤換請求，公開狀態待確認」）→ 找辦公區**阿明組長**回報 → 回值班桌交班確認撤換與公開狀態。
   - **未完成補救**：誤傳後直接回值班桌交班，確認交班畫面明確列出尚未處理的緊急項目。

## 日後部署到 GitHub Pages

1. 建立新的公開 Repository（例如 `before-sending-game`）。
2. **僅上傳本 `before-sending/` 資料夾內的檔案**（`index.html`、`css/`、`js/`、`README.md`）。
3. 到 Repository 的 **Settings → Pages → Build and deployment**，選擇 `Deploy from a branch` → `main` → `/ (root)` 儲存即可。
